# Documentation

Design notes, audits and fix logs for QUANTA, written while the project was built. They are
dated working records, not a stable specification.

Audit and fix-log documents refer to evidence artifacts (screenshots, raw test output, scratch
data) that were produced during development. Those artifacts are not included in this
repository, so those references will not resolve. The conclusions in each document stand on
their own.

Start with [LIVE_MODEL_VALIDATION_STATUS.md](LIVE_MODEL_VALIDATION_STATUS.md) for what the live
model has and has not demonstrated, and [QUANTA-ALPHA/README.md](QUANTA-ALPHA/README.md) for the
design blueprint. The code is released under the MIT License; see [../LICENSE](../LICENSE).
