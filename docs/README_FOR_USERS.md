## 🚀 Quick Start (3 Steps!)

### Step 1: Install Python
Download and install **Python 3.9 or higher** from:
👉 **https://www.python.org/downloads/**

**During installation:**
- ✅ Check "Add Python to PATH"
- ✅ Click "Install Now"

### Step 2: Install Dependencies
Open **Terminal** (Mac) or **Command Prompt** (Windows), navigate to this folder, and run:

```bash
pip install -r requirements.txt
```

⏱️ Takes ~1-2 minutes

### Step 3: Run QUANTA ELITE
```bash
python run_quanta_elite.py
```

🎉 **You're all set!**

## 🎯 Understanding Recommendations

### Signal Types
- 🔥 **STRONG_BUY** - High conviction, act soon
- 📈 **BUY** - Strong setup, add to portfolio
- 💎 **ACCUMULATE** - Build gradually
- ⏸️ **HOLD** - Monitor, no action
- 📉 **AVOID** - Stay away

### Risk/Reward Ratio (R:R)
**Example: 3.0:1**
- For every $1 you risk, you can make $3
- Higher is better
- Look for R:R > 2:1

### Win Probability
- Statistical likelihood of reaching target
- Based on backtesting + current conditions
- >60% is good, >70% is excellent

### Timeframe
- **3-6 months** - Short-term swing trade
- **6-12 months** - Medium-term position
- **12+ months** - Long-term hold

## 🔧 Troubleshooting

### "pip: command not found"
- Python wasn't installed correctly
- Reinstall Python and check "Add to PATH"

### "Module not found" errors
- Run: `pip install -r requirements.txt` again
- Try: `python3 -m pip install -r requirements.txt`

### Scan takes too long
- Choose "Quick" scan instead
- Close other programs
- Check internet connection (needs live data)

### No recommendations found
- Try different scan type
- Check if market is open
- Adjust capital amount (may be too low)
